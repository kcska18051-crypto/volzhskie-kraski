# Баннер «Краска под вашу поверхность» — 13 октября 2026

Заменена седьмая плашка после шести направлений применения. Согласованные заголовок, описание и CTA постоянны; меняется только предметная иллюстрация и её содержательная подпись. На desktop — текст слева, медиа справа; на mobile — текст/CTA сверху. Высота медиа, подписи и управления фиксирована, смена кадров не двигает страницу. Услуга обращения lkm, видимый редактируемый контекст «Подбор материала под поверхность»; форма остаётся единственной.

## Что включено
Публично показываются два общих металлических сценария: гладкая стальная панель и другая стальная деталь с изгибами. Они опираются на ранее подтверждённое применение материалов по металлу и не являются изображениями продукции/заказов клиента.

Алюминий, пластик и оцинковка подготовлены как approved:false / enabled:false. В доступных документах проекта нет подтверждения конкретных систем покрытия для этих оснований. Они показываются только при ?surfaces=review, с явной пометкой согласования. Для алюминия/пластика указано, что система покрытия и грунт подбираются под основание. Оцинковка остаётся выключенной до подтверждения. Дерево, бетон, стекло и универсальные обещания не добавлены.

Конфигурация — src/surface-config.js, экспорт доступен через src/media-config.js. Количество и состав легко менять. scripts/sync-surface-fallback.mjs при сборке синхронизирует первый разрешённый кадр с HTML для режима без JS; пустой список оставляет декоративный fallback и полный текст/CTA.

## Анимация
Автосмена начинается каждые 3 секунды, crossfade 700 ms после загрузки следующего изображения. Текущий кадр остаётся под новым до завершения перехода, поэтому нет провала в нулевую прозрачность. Начатое затухание спокойно завершается, затем пауза останавливает новые переходы. Ручная пауза сохраняется после ухода курсора/фокуса. Таймер остановлен вне viewport, при скрытой вкладке, фокусе/наведении, открытой модалке и reduced motion. При reduced motion первый кадр статичен; разрешён ручной выбор без анимации. Без aria-live для автосмены.

## Проверено
- Автосмена и постоянная высота 486px в desktop-композиции; ручная пауза, hover/focus, уход за экран. Симуляция скрытой вкладки проверена отдельным локальным QA-fixture и unit-тестом.
- 0, 1, 2 и 5 кадров: при одном/пустом списке управление скрыто, место сохраняется. Review-кадры дают неизменную высоту внутри review-композиции.
- Ошибка следующего изображения сохраняет текущий кадр; ошибка первого переключает на доступный второй; две ошибки дают стабильный fallback с доступной CTA.
- Reduced motion: статичное изображение, ручное переключение без transition. Без JS: текст, CTA и первый разрешённый стальной кадр.
- Кнопка открывает одну форму с правильными услугой/контекстом, Escape возвращает на страницу.
- Мобильная, планшетная и настольная композиции; отсутствие горизонтального переполнения и перекрытых контролов.
- 13 unit-тестов, сборка для локального просмотра и GitHub Pages.

## Медиа
Пять самостоятельных CGI-иллюстраций созданы встроенным ImageGen. Оригиналы оставлены в generated_images; финальные файлы сохранены в public/assets/surface-*.webp: desktop 1536×1024, mobile 800px по ширине. Промпты — SURFACE_IMAGE_PROMPTS.json. Это цифровые предметные изображения, не документальная съёмка и не подтверждение технической применимости. Общий свет, синий фон, красное покрытие, различимая геометрия и материалы.

ТЗ — SURFACE_BANNER_SPEC.md. Скриншоты — v11-surface-desktop.png и v11-surface-mobile.png. Публичный якорь #surfaces; review можно совместить с партнёрами: ?preview=partners&surfaces=review#surfaces. Backend формы по-прежнему ожидается.
