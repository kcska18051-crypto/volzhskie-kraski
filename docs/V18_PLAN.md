# Компактная интерактивная география V18

После опубликованных V16/V17: сократить поля и пустое пространство SVG без обрезки географических контуров/подписей. Desktop карта 84vw до 1480px, viewBox по реальным границам; mobile отдельная сохранённая ортографическая проекция с меньшим пустым полем. CTA и три компактных переключателя рядом над картой, без карточек/pop-up.

Три условных направления: один внутренний ориентир России (100E/64N), Беларуси (27.5E/53.5N), Казахстана (68E/48N). Это иллюстрация географии работы, не реальные города поставок. Проверить попадание в полигоны исходных Natural Earth, поставить конечные маркеры, убрать морские окончания. Ярославль остаётся единственным производственным узлом. Беларусь/Казахстан подписать рядом с контурами, для Беларуси короткая выноска.

Мягкое выделение страны при pointer hover и focus; touch/click выбирает страну, кнопки доступны клавиатуре. Выбор меняет только редактируемый контекст CTA lkm. Motion один раз, reduced/static/noJS доступны.

Тесты до реализации: геометрия всех конечных точек и viewBox, пустой/неизвестный выбор страны, контексты. Затем проверки 360/390/768/1366/1440/1920px, hover/focus/touch, маркировка, формы, clipping/отступы, motion/reduced/noJS. Прежние правки сохранить; отчёт/HANDOFF/скриншоты, тесты/сборки, публикация текущей ветки.
