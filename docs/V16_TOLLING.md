# Давальческая секция — адресная правка V16

После завершения и публикации географии V15 перенесены строка «Сначала оценим техническую возможность, затем согласуем условия выполнения» и CTA «Обсудить переработку» под список трёх операций в левой колонке. Отступ от списка 24 px. Правая серая зона и результат остались справа.

Один экземпляр текста и кнопки в DOM, CSS Grid меняет размещение. На mobile порядок: операции → медиа/результат → условия/CTA, отступ после результата 28 px. На desktop/tablet кнопка помещается в левую колонку.

Проверены 1366/768/390px, порядок, отступы и отсутствие переполнения/дублей. Выбор третьей операции с клавиатуры и открытие формы сохраняют tolling и редактируемый повод «Давальческая переработка: Другая технологическая операция»; закрытие возвращает фокус. JS операций и формы не менялся. География V15 и остальные секции сохранены.

20 тестов и статические сборки проходят. CSS получает v16 для обновления кэша. Публикация в текущей ветке codex/art-direction-v2 через Pages. Реальная фотография операции по-прежнему ожидается; согласованный серый слот сохранён.
