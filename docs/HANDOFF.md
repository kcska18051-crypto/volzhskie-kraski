# Контекст для продолжения с другого компьютера

## Проект
Лендинг «Волжские краски — Инженерия цвета». Реализованы первая версия, арт-директорские правки V2 и дополнительная правка блока партнёров. Пользователь утвердила продолжение работы и поручила создать публичный GitHub-репозиторий и ссылку просмотра.

## Утверждённая основа
Сохранить оригинальный логотип, Onest, Deep Navy/Signal Red, чередование светлых и тёмных секций, красное смешивание краски в hero. Не переделывать концепцию с нуля. Статический HTML/CSS/ES-модули, без зависимостей. См. V2_PLAN.md и V2_REPORT.md.

## Реализовано
Равный вес услуг в hero; предметные макрообразы покрытий; шесть отраслей с контекстной заявкой; четыре шага индивидуального заказа; маршрут давальческой переработки; пять меняющихся иллюстраций процесса; пять медиазон производства и контроля. Партнёры расположены после производства перед FAQ: «Нам доверяют», «Компании и бренды, с которыми мы сотрудничаем».

Партнёры настраиваются в src/media-config.js: восемь пустых слотов partners, количество свободно меняется. Нужны name, src и approved:true. Пока список пуст, секция скрыта. Несогласованные и незагрузившиеся логотипы не отображаются. Не придумывать бренды и не использовать неподтверждённые логотипы.

## Ограничения и ожидаемые материалы
- Все текущие предметные изображения подписаны как демонстрационные; не выдавать их за реальные кадры завода или продукции.
- Ожидаются реальные кадры мощностей, специалистов, НИЛ, ОТК и контроля образцов. См. MEDIA_REQUIREMENTS.md.
- Ожидаются согласованные партнёрские логотипы, endpoint формы и юридические документы.
- Форма не имитирует отправку: успех только после ответа сервера success:true.
- 120 кг и 3 дня относятся только к ЛКМ. Железнодорожное применение — ремонтная окраска, без утверждений о заводской сертификации.

## Проверки и запуск
Node.js 20+, установка пакетов не требуется. npm run dev — локальный просмотр; npm test — три теста; npm run build — статическая сборка. Браузерная проверка V2: 35 сценариев, восемь ширин, axe без нарушений. Партнёрская сетка дополнительно проверена на мобильном и настольном экране с временными геометрическими изображениями; они не сохранены в проекте.

## GitHub
Рабочая ветка codex/art-direction-v2. GitHub Pages автоматически публикуется при push в эту ветку. scripts/build-pages.mjs адаптирует пути для /volzhskie-kraski/. Для другого имени репозитория изменить base в этом файле.

На рабочем компьютере клонировать репозиторий, переключиться на рабочую ветку и открыть папку в Codex. Этот файл и остальные документы docs сохраняют решения и текущее состояние; история чата доступна по отдельной ссылке, переданной пользователю.

Исходные задания пользователя сохранены в BRIEF_V1.md и BRIEF_V2.md.
