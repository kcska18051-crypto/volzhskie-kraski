# Седьмой элемент галереи — актуальное ТЗ V14

Заголовок «Не нашли то, что нужно окрасить?». Описание «Шесть направлений — только примеры. Расскажите о вашей детали или поверхности: рассмотрим материал под задачу и условия эксплуатации». CTA «Обсудить мою задачу», услуга lkm, редактируемый повод иной детали/поверхности.

Все пять существующих CGI-иллюстраций публично одобрены как примеры запросов для обсуждения: стальная панель, стальная деталь, алюминиевая деталь, пластиковая деталь, оцинкованный элемент. approved означает согласование иллюстрации; purpose:discussion-example не подтверждает систему покрытия или техническую применимость. Это не кейсы заказчиков, не обещание универсального состава и не подтверждение PP/PE/ABS.

Баннер продолжает шесть отраслевых карточек на общем фоне без отдельной тяжёлой тёмной плашки. Desktop текст слева, медиа справа; mobile последовательно. Все изображения целиком, object-fit:contain в постоянной зоне 3:2. Исходные кадры сохраняются, без растягивания и обрезки.

Бесконечный цикл 3 секунды, crossfade 700ms, предыдущий кадр остаётся под новым до завершения перехода. Следующий кадр предзагружается. Высота, заголовок, описание и CTA постоянны. Остановка вне экрана, при скрытой вкладке, открытом диалоге, фокусе внутри управления и ручной паузе; указатель мыши на иллюстрации не останавливает цикл. Ручной выбор ставит паузу, кнопка позволяет продолжить. Reduced motion — статичный первый кадр и ручной выбор без перехода. Без JS первый кадр и CTA доступны.

Повреждённые кадры исключаются, текущий сохраняется; при отсутствии всех источников остаётся нейтральный фон и честное сообщение. Для 0/1 доступных кадров управление скрыто. Не добавлять новые основания без отдельного согласования.
