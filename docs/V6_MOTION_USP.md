# Плавность появления и УТП — 13 октября 2026

Выполнено после согласованной правки палитры/скруглений (V5). Сохранены тексты, карта, партнёры, форма и все предыдущие улучшения.

## Причины и исправления
Ранее блоки были видимыми по умолчанию, а при входе в viewport начиналась keyframe-анимация от opacity:0. Это создавало видимое исчезновение перед появлением. Теперь JS подготавливает только элементы ниже видимой области; IntersectionObserver начинает переход на 100 px раньше viewport. Переход opacity/translateY длится 0,9 с, перемещение 12 px, без задержки карточек. После перехода подготовительный класс удаляется, наблюдение прекращается. Элементы, уже видимые при старте, не скрываются. Повторная прокрутка не перезапускает появление. Карта также подготавливается заранее; линии рисуются мягче, один раз. Отсутствие IO/ошибка и reduced motion оставляют контент видимым.

УТП унаследовали justify-content:center, align-items:center и мобильные nth-child-разделители. Эти правила переопределены в области proof-band. На широком экране четыре колонки, на телефоне две. Заголовки и описания используют общие строки CSS subgrid, поэтому заголовок в три строки на 360 px не сдвигает описание относительно соседнего. Для старых браузеров оставлен простой fallback с резервом высоты. Границы убраны. У блока появился якорь #advantages.

## Проверки
9 unit-тестов проходят; статическая сборка и сборка GitHub Pages. Проверены ширины 360/390/768/1280/1440/1920/2560 без горизонтального переполнения. Координаты заголовков и описаний совпадают в каждой строке сетки, включая три строки заголовка на 360 px. В браузере проверены первичное появление и повторная прокрутка: появившиеся карточки остаются opacity:1 без keyframe-анимации. Reduced motion: нет подготовленных скрытых блоков, партнёры статичны. Без JS контент видим и форма одна. Проверки V5 формы, контраста и скруглений сохранены. Скриншоты v6-usp-desktop.png и v6-usp-mobile.png.

Палитра V5: основной #203B63, глубокий #142944, акцент #ED1B24; кнопки #DC1520 и текстовый красный #CF1621 для контраста. Логотип не менялся. Форма по-прежнему без endpoint; партнёры пусты, для их согласования использовать ?preview=partners.
