# Форма заявки: задачи перед запуском

- Подключить реальный обработчик через integration.requestEndpoint; проверить доставку заявок и вложений получателю.
- Сервер должен проверять поля и файлы и возвращать JSON с success: true только после принятия заявки.
- Подключить утверждённые политику, согласие и пользовательское соглашение через integration.privacyUrl, consentUrl и agreementUrl. Тексты не предоставлены.
- Провести сквозную проверку реальной отправки, ошибок и повторной попытки на опубликованном сайте.

До подключения обработчика форма явно сообщает о недоступности онлайн-отправки и не имитирует успех. Состояния ответа сервера проверены с тестовым обработчиком в браузере.
