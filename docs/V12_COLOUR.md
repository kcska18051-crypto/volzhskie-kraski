# Один согласованный цвет — 13 октября 2026

Переработан существующий блок, без дубликата. Согласованные заголовок и описание объясняют подбор по детали, выкрасу или образцу эмали и сравнение следующих партий с одним эталоном.

В одной композиции — отдельный образец с подписью «Согласованный эталон» и по несколько одинаковых панелей корпуса в группах «Первый заказ» / «Повторный заказ». Вместо трёх абстрактных пластин используются предметные детали с отверстиями, креплениями и загнутыми краями. Все пять изображений используют один неизменённый исходник, одинаковые ракурс/свет/цвет, без цветовых фильтров и отдельных градиентов для разных заказов.

Под визуалом: «Получаем образец → согласуем выкрас → проверяем следующие партии». Проверка качества отделена строкой «Помимо цвета проверяем качественные показатели материала». Конкретные показатели, измерения и обещание нулевого отклонения не добавлены.

Иллюстрация создана встроенным ImageGen как прозрачный CGI-cutout. Это объяснение процесса, не реальные заказы клиента. Промпт — COLOUR_IMAGE_PROMPT.md. Финальные файлы: public/assets/colour-order-panel.webp (1536×1024) и colour-order-panel-mobile.webp (800px по ширине), прозрачность сохранена. Оригинал оставлен в generated_images. Одно изображение загружается из кеша для всех повторов.

Desktop: три группы рядом. Mobile: эталон сверху, первый/повторный заказ рядом ниже, последовательность действий вертикально. Мягкое однократное появление групп использует уже подготовленную reveal-композицию; видимый контент не сбрасывается. При возврате группы остаются opacity:1; reduced motion и отсутствие JS дают полноценную статичную композицию.

Проверено: 360/390/768/1366/1920 без переполнения, читаемые подписи, одинаковый src во всех группах, пять экземпляров детали и одна секция. Проверены возвращение к блоку, reduced motion и отсутствие JS. Существующие 13 тестов, статическая сборка и GitHub Pages. Скриншоты v12-colour-desktop.png и v12-colour-mobile.png. Новый баннер поверхностей и прочие функции сохранены; блок компании пока не перерабатывался.
