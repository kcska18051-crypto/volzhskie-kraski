# Инженерия цвета

Утверждённое ТЗ пользователя является основой дизайна. Исходный пресейл используется только для контента и неизменённого файла логотипа. Репозиторий изначально пуст, без определённого стека.

## Дизайн

Deep Navy #101D34, Signal Red #E63742, Cool White #F3F5F7, Steel #8D9BAE. Заголовки и текст — Onest; технические подписи — системный моноширинный шрифт. Контейнер 1440 px, асимметричные композиции, выразительный контраст размеров и чередование светлых и тёмных разделов.

Первый экран: текст слева, демонстрационный крупный план смешивания красной краски справа, две равнозначные ссылки на услуги и нижняя доказательная полоса. Изображение явно подписано как визуальная концепция. Файл логотипа из пресейла используется без обработки. Отсутствующие документальные материалы производства имеют редакционные медиазоны.

## Архитектура

Семантический HTML, CSS и небольшие ES-модули без UI-фреймворка и внешних runtime-зависимостей. Node.js предоставляет локальный сервер и копирование статической сборки. HTML переносится в шаблон Битрикс; контент, медиа и интеграция формы разделены. Все ключевые тексты доступны без JavaScript. JS отвечает за меню, отраслевую витрину, этапы давальческой схемы, раскрытия и форму.

Медиа-конфигурация содержит desktop/mobile источники, постеры, подписи и точки кадрирования. Без видео остаётся полноценный статичный экран. Движение отключается при prefers-reduced-motion.

## Проверка

Проверить сборку, реальные взаимодействия, отсутствие горизонтального скролла на 375–1920 px, клавиатурную навигацию и доступность. Форма валидирует имя, один способ связи, согласие и файл; до подключения endpoint не показывает сообщение об отправке. Контакты из пресейла и юридические документы требуют подтверждения перед публикацией.
