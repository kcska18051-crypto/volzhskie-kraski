# Медиа — актуальная версия

Сменные источники находятся в src/media-config.js, файлы в public/assets/. Для реальных кадров задать desktop/mobile, alt, position/mobilePosition, demonstration:false. Статичные picture в index.html синхронизировать с конфигурацией для режима без JavaScript.

Текущие hero, макрообразы и отрасли — иллюстрации; их происхождение описано в docs/V4_REPORT.md. Они не являются документальной съёмкой завода или доказательством применения продукции. Подписи над изображениями и технические надзаголовки не возвращать.

| Слот | Кадрирование и содержание |
|---|---|
| hero-poster | Смешивание справа, спокойная область слева; desktop 3:2, mobile отдельный вертикальный кадр |
| material-acrylic / material-alkyd | Различимые макрофактуры окрашенного металла; горизонтальная область, без текста внутри изображения |
| application-gates / racks / forklift / machinery / transport / railway | Шесть самостоятельных предметных кадров 3:2; название и действие под изображением. Не представлять как кейс без подтверждения. Railway — ремонтная окраска |
| tolling-production | Реальная согласованная операция; горизонтальная зона около 3:2, текст рядом. До получения фото — SVG-схема |
| equipment | Один основной широкий кадр собственного производства, около 3.3:1 desktop и 1.3:1 mobile; предоставить отдельное мобильное кадрирование |
| laboratory | Работа НИЛ с рецептурой и эталоном, горизонтальный кадр |
| quality-control | Реальная процедура ОТК, горизонтальный кадр |

Для крупных зон desktop исходники от 1600–2400 px, mobile от 800 px. Сохранять объект внутри центральных 60% кадра. Отдельных зон team, custom-etalon и control-samples в текущей раскладке нет; старые конфигурационные ключи зарезервированы.

Для видео задать video.desktop/video.mobile и оба статичных постера; без мобильного видео остаётся фото. Управление паузой, reduced motion и saveData уже предусмотрены в main.js. Не подключать чужие цеха как документальные кадры предприятия.

Логотипы партнёров — только согласованные оригиналы с сохранением пропорций. Массив partners можно расширять и сокращать; approved:true, name и src обязательны, ошибка загрузки скрывает элемент. Нейтральные слоты показываются исключительно в явно отмеченном режиме ?preview=partners.

## Баннер поверхности

public/assets/surface-*.webp: два публичных стальных изображения и три выключенных слота. Источники — src/surface-config.js; утверждение технических оснований и включение — отдельное решение. ?surfaces=review показывает предварительные кадры с оговорками. Для нового кадра задать desktop/mobile, короткое название и alt, approved/enabled; после изменения выполнить сборку для синхронизации первого кадра без JS. См. docs/V11_SURFACES.md и промпты docs/SURFACE_IMAGE_PROMPTS.json.
