# Волжские краски · Инженерия цвета

Адаптивный интерактивный лендинг для первого арт-директорского просмотра. Семантический HTML, локальный Onest, CSS, ES-модули; без runtime-библиотек. Исходное ТЗ реализовано в пустом репозитории. Логотип из пресейла сохранён побайтово без изменений.

## Запуск

Требуется Node.js 20+; установка npm-пакетов не нужна.

```sh
npm run dev
```

Открыть http://127.0.0.1:5173/ . Сервер доступен только на этом компьютере.

```sh
npm test
npm run build
npm run preview
```

Сборка — `dist/`, готовая для статического хостинга или переноса в шаблон 1С-Битрикс. Перед preview остановить dev-сервер (Ctrl+C), поскольку оба по умолчанию используют порт 5173. Другой порт задаётся переменной `PORT`.

В этой Windows-сессии терминальные процессы не могли создавать файлы внутри Documents. Сборка и бинарные файлы сохранены через файловый runtime Codex, без изменения системных настроек. Если `npm run build` на этом компьютере выдаёт ошибку доступа/создания файла, это ограничение среды; готовый `dist/` уже есть. Сервер и unit-тесты запускаются обычным Node.js.

## Структура

- `index.html` — весь контент, семантические секции, форма, доступные нативные раскрытия.
- `src/styles.css` — неизменённая основа дизайн-системы.
- `src/v2.css` — композиционные правки V2, размеры, медиазоны и motion с reduced-motion.
- `src/content.js` — шесть отраслей, четыре этапа индивидуального заказа, пять этапов переработки.
- `src/process-scenes.js` — предметные объясняющие иллюстрации пяти этапов; это не изображения оборудования предприятия.
- `src/main.js` — навигация, вкладки, медиа, раскрытия и legal-dialog.
- `src/form.js` — валидация и адаптер отправки.
- `src/media-config.js` — источники медиа и настройки backend/юридических документов.
- `MEDIA_REQUIREMENTS.md` — требования к каждому сменному медиаслоту.
- `docs/V2_REPORT.md` — актуальный отчёт о правках и проверках. `docs/DELIVERY_REPORT.md` сохранён как отчёт V1.
- `tests/form.test.mjs` — unit-тесты данных заявки.
- `tests/browser-checks.js` — повторяемые проверки с Playwright Page и axe-core. Эти инструменты нужны только для QA, не для сайта.
- `docs/v2-browser-checks.json` — фактический результат последнего браузерного прогона.

## Backend

В `src/media-config.js` указать реальный `integration.requestEndpoint`. По умолчанию `null`: форма валидирует данные, но прямо сообщает, что запрос не отправлен. Введённые данные не записываются в localStorage, куки или аналитику.

Запрос: `POST`, `multipart/form-data`, поля `service` (`lkm`, `tolling`, `other`), `company`, `name`, `contact`, `task`, `consent=true`, необязательный `context` (выбранная отрасль или эталон), необязательный `attachment`, необязательный `csrfToken`. Контекст виден посетителю и может быть удалён перед отправкой.

Успех только при успешном HTTP-статусе и JSON `{ "success": true }`. Ошибка/таймаут не очищают форму. Таймаут 20 секунд. Рекомендуется обработчик на том же домене. Для Битрикс передать session/CSRF-токен в `integration.csrfToken`, а серверную проверку настроить в обработчике.

Backend должен повторно проверить имя и контакт, согласие, размер/тип и фактическое содержимое файла, ограничить частоту обращений, безопасно сохранить вложение, отправить заявку ответственному сотруднику или CRM. Не доверять проверкам браузера. Доступ к данным, сроки хранения и журналирование определяются утверждёнными документами оператора.

`integration.privacyUrl` и `integration.consentUrl` заполняются ссылками на утверждённые документы. Пока вместо юридического текста открывается явное уведомление о его отсутствии.

## Перед публикацией

Подтвердить контакты, сведения о производстве и окончательный состав операций; предоставить реальные медиа, партнёрские логотипы и юридические документы; подключить backend. Удалить `noindex, nofollow` после согласования и настроить основной домен. Реальная отправка и публикация не выполнены.

Если сайт размещается в подпапке, адаптировать абсолютные пути `/src/` и `/assets/` к базовому адресу. При переносе в Битрикс заменить asset-пути на каталог шаблона, сохранив anchor-ID секций.

Шрифт Onest распространяется по SIL Open Font License; лицензия находится в `public/assets/OFL-Onest.txt` и копируется в сборку.

## Партнёры

Секция «Нам доверяют» находится после производства и перед FAQ. В `src/media-config.js` массив `partners` содержит восемь пустых редактируемых слотов. Для каждого согласованного партнёра задайте `name`, `src` (например, путь к оригинальному SVG/PNG в `/assets/`) и `approved: true`. Добавляйте и удаляйте записи массива, чтобы менять количество логотипов. Сохраняйте фирменные цвета; для равного визуального веса используйте оригиналы без избыточных прозрачных полей. Изображения сохраняют пропорции. Несогласованные, пустые и незагрузившиеся слоты скрываются; при отсутствии готовых логотипов скрывается вся секция. Отдельных страниц и ссылок партнёров нет.
